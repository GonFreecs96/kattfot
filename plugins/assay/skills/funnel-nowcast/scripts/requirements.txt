# Dependencies for the funnel-nowcast helper (funnel_nowcast.py).
#
# Only `pyyaml` is mandatory: the default engine is sqlite, which loads the
# committed fixture CSVs into an in-memory database using nothing but the standard
# library, so a fresh clone runs this skill with no cloud account. The chain-ladder
# estimator itself (Mack factors, MSEP, lognormal quantiles) is pure stdlib —
# `math` and `statistics.NormalDist` — deliberately: the earlier outline priced in
# numpy/scipy for a bootstrap, and the shipped closed-form Mack variance needs
# neither.
#
# `google-cloud-bigquery` is needed only for ASSAY_ENGINE=bigquery, where the
# query runs as the individual human user via ADC. A missing dependency there is a
# hard error (exit 3), never a silent fall back to fixture numbers.
#
# Install into a venv so you don't fight your system Python (PEP 668):
#   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
pyyaml>=6.0.3                  # module registry + funnel-spec parsing
google-cloud-bigquery>=3.41.0  # ASSAY_ENGINE=bigquery only; queries run as you via ADC
