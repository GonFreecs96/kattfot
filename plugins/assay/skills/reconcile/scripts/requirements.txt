# Dependencies for the reconcile helper (reconcile.py).
#
# `pyyaml` is mandatory: reconcile re-runs the metric through the query-metric
# helper (which parses metric frontmatter) and reads an external artifact's
# manifest for the definition-drift check.
#
# The warehouse client library is needed only for ASSAY_ENGINE=bigquery, where
# every re-run executes as the individual human user via ADC. It is listed here
# because the helper's own error message on that path points at this file, and a
# missing dependency there is a hard error (exit 3) — never a silent fall back to
# fixture numbers.
#
# Install into a venv so you don't fight your system Python (PEP 668):
#   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
pyyaml>=6.0.3                  # metric frontmatter + artifact manifest parsing
google-cloud-bigquery>=3.41.0  # warehouse engine only; re-runs execute as you via ADC
